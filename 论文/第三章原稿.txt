3需求分析
本章针对基于 SpringBoot 的“咖咖商城”在线销售系统的设计与实现进行全面的系统分析。主要内容包括系统功能需求分析、系统用例分析以及系统可行性分析等关键环节。其中，功能需求分析进一步梳理了系统的业务边界，详细涵盖了前台用户端的商品浏览与搜索、购物车与订单结算、AI 智能咨询模块，以及后台管理端的系统用户管理、商品与分类维护、订单发货处理和评论审核等核心子模块。
3.1 可行性分析
3.1.1 技术可行性
本系统采用 SpringBoot 作为核心开发框架，其“约定优于配置”的特性极大简化了 Spring 应用程序的初始化搭建与开发过程。
SpringBoot技术的可行性可以从以下几方面来进行分析：
（1）生态系统方面： Spring 社区庞大且活跃，提供了海量的开源项目和解决方案，为开发过程中遇到的问题提供了强大的技术支持。
（2）开发效率方面：SpringBoot 集成了大量常用的第三方工具与库（Starter 依赖），如 Web 开发、数据库连接、模板引擎等，能够让开发人员迅速搭建起一个功能完备的 Web 应用程序，显著缩短了开发周期。
（3）可扩展性方面：SpringBoot 提供了丰富的插件机制与可扩展点，开发人员可以根据业务需求灵活选择适宜的扩展与插件（如集成 Redis 缓存、RabbitMQ 消息队列等），以满足“咖咖商城”未来业务增长的需求。
SpringBoot 框架通过集成核心功能，显著提升了项目的开发效率和系统稳定性，对于“咖咖商城”这类垂直电商系统而言，选用 SpringBoot 技术是一项切实可行且明智的决策。
3.1.2 经济可行性
本项目的开发成本主要集中在软件研发的人力成本和少量的服务器租赁成本。由于采用了开源的 Springboot，软件授权成本几乎为零。

3.1.3 社会可行性
“咖咖商城”旨在利用信息化手段整合咖啡零售资源，在推进该网站的建设与运营过程中，必须充分考虑到项目的社会可行性，保障运营的合法性与合规性。
首先，本系统涉及用户个人信息（如手机号、收货地址）的收集与处理，因此在开发过程中严格遵守了国家关于网络安全及数据保护的法律法规。Zhao Z.（2025）在系统安全防护评估中所强调的数据隐私合规策略，为本商城的加密与脱敏处理提供了重要的指导参考[21]。
其次，商城的运营高度依赖网络技术与互联网，必须确保交易环境的安全性。在系统的建设与运营阶段，将采取有效的网络安全措施（如权限校验、SQL 注入防御），防止数据泄露和恶意攻击等潜在风险。
最后，该系统的建立有助于推广咖啡文化，满足年轻群体对高品质生活的追求，符合社会消费升级的趋势。综上所述，“咖咖商城”在遵循法律法规及顺应社会发展方面表现良好，从社会可行性角度考量，其建设与运营是完全可行的。
3.2 功能需求分析
3.2.1 功能架构
“咖咖商城”是一个基于 SpringBoot 框架构建的 B/S 架构电商系统。系统利用 SpringBoot 框架的持久层（MyBatis）与 MySQL 数据库进行高效的数据交互，业务逻辑层处理核心交易流程，并通过控制层（Controller）将处理结果传输至视图层，最终在前端页面上以直观、友好的方式展示给用户。正如 Shao W 等（2024）在在线订餐系统中所强调的，稳定的数据流转是业务场景适配的基础[20]。该架构设计保证了系统的高内聚低耦合，便于后期的维护与扩展。如图3-1所示。
