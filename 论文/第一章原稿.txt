1绪论
1.1 研究背景
随着互联网技术的飞速发展和智能手机的普及，线上购物已成为现代人不可或缺的生活方式。咖啡作为一种全球性的饮品，拥有庞大的消费群体。
在数字化浪潮下，信息技术的进步为零售业提供了新的销售手段。正如王培培（2024）在其研究中指出，线上商城系统能够帮助商家突破传统销售场景的限制，实现商品信息的高效传递[1]。汤智宏（2025）在线上书店的设计中也表明，良好的线上平台能显著拓宽销售渠道并提升用户粘性[2]。通过互联网，商家可以便捷地传递商品信息，吸引消费者的注意力。
此外，借助信息化手段打通管理链路，正如韦彩仁等（2024）所追求的高效流转，能显著提升行业效率[3]。针对具有独特风味的饮品，沈莹等（2025）在茶叶交易平台的研究中指出，垂直领域的电商平台更能精准触达目标群体[4]。
然而，目前市面上服务于咖啡爱好者的专业化、用户体验优良的在线商城系统相对较少。现有的一些平台可能功能单一，用户体验不佳，或者缺乏针对咖啡这一特殊商品（如产地、烘焙度、风味等）的深度优化，难以满足广大咖啡爱好者日益增长的线上购物需求，提供一个集便捷性、专业性和良好用户体验于一体的在线商城系统变得尤为重要。
1.2 研究目的与意义
1.2.1 研究目的
近年来，国内咖啡消费市场规模持续扩大，消费者对于咖啡豆的品质、产地以及风味特征有了更加细致的追求。然而，综合类电商平台在展示这类专业性较强的商品时，往往难以提供精准的信息分类与导购服务；另一方面，许多独立咖啡品牌和实体店铺受限于技术成本，缺乏专属的线上直销渠道。
基于上述行业现状，本项目的核心目的在于设计并实现一个专注于咖啡品类的垂直在线销售平台——“咖咖商城”。在功能构建上，不仅致力于打通从商品浏览、购物车管理到订单结算的完整交易闭环，还期望通过引入个性化的智能问答服务，降低消费者的决策门槛。总体而言，本作旨在利用现代化的 Web 开发技术，为买卖双方搭建一个兼具专业性与实用性的互动交易桥梁。
1.2.2 研究意义
本项目的开发不仅具有一定的实际应用价值，也是对大学期间所学计算机专业知识的一次全面检验，其研究意义主要体现在以下两个方面：
在实际应用层面，该系统的开发能够有效改善传统线下咖啡店依赖人工记录、管理效率低下以及客流受限等问题。这种实际应用的落地能显著提升管理效率，如同杨玉等（2025）在物业系统中实现的精细化数字管理[5]。商家可以清晰地掌握每天的订单状态和商品库存变动，及时调整进货和烘焙计划，减少咖啡豆过期或积压的风险。对于消费者而言，该平台过滤了无关的商品信息，提供了清晰、专业的咖啡选购环境。结合系统内的智能咨询等辅助服务，能够大幅降低新手的挑选难度，提升用户的购物体验和复购意愿。
在技术实践层面，本项目的开发是对软件工程流程的一次完整实践。参考陆向艳等（2025）基于 SpringBoot 打造高效预约系统的经验，本项目也致力于将理论知识融会贯通[6]。这不仅验证了主流 Web 开发技术在实际业务中的可行性，也切实锻炼了从需求分析、数据库建模到代码编写与 Bug 调试的动手能力，为今后步入软件开发行业积累了宝贵的工程经验。
1.3 国内外研究现状
1.3.1 国内研究现状
在国内，随着电子商务的加速发展和 SpringBoot 等先进开发框架的广泛应用，基于 Web 的商城系统开发已经相当成熟。薛楠楠等（2025）在数据库系统的研究中证实了 SpringBoot 结合前端框架的运行稳定性[7]。黄蓬国等（2025）在管理系统的构建中也强调了底层架构对业务流转的强大支撑能力[8]。
目前的垂直电商正在向精细化运营方向发展，除了提供基础商品服务，也越来越注重用户体验和社区建设。魏培阳等（2025）在实训平台中引入了智能化与定制化模块，代表了国内平台的发展趋势[9]。同时，类似牛子逸（2025）在评阅系统中采用的数据交互机制，也被广泛应用于各类现代电商平台中[10]。而在处理电商核心交易时，周贤武（2024）对高并发网购平台的后台管理进行了深入研究，为订单的并发处理提供了理论参考[11]。
然而，针对“咖啡”这一垂直细分领域的专业化商城相对较少。目前的大多数平台仍以综合性电商为主，缺乏对咖啡文化的深度挖掘和专业展示，无法完全满足现代咖啡爱好者对专业知识和社交互动的需求。
1.3.2 国外研究现状
在国外，电子商务起步较早，技术体系和市场应用都较为完善。在垂直领域的电商平台建设上，国外往往更注重社区生态的打造与个性化推荐算法的应用。当前的发展趋势致力于通过深度的数据分析来优化用户体验，例如利用协同过滤等推荐机制进行精准的商品推荐，从而有效提高用户的购买转化率并增强平台的用户粘性。
在技术体系层面，Java 生态依然占据主导地位。特别是在企业级应用开发中，Spring 框架及其生态圈（如 SpringBoot）凭借其强大的生态支持和卓越的稳定性，被广泛应用于构建复杂的电商后端系统。实践证明，打造一个健壮的后端架构是保障电商各项业务流程高效、顺畅运行的核心关键。
总体而言，当前国内外在电商系统的基础技术实现上已趋于成熟，但在垂直细分领域的深度优化方面仍有广阔的探索空间。垂直领域的商城系统必须紧密结合具体行业特性进行深度定制与优化，这也深刻凸显了当前咖啡商城面临的市场空白与技术挑战。此外，如何将 SpringBoot 等成熟技术更深入、有效地融入垂直电商的设计体系中，确保技术实现与实际业务场景的高度适配，从而进一步提升系统的整体稳定性和运行性能，依然是目前系统研发的重要聚焦方向。
1.4 主要研究内容
（1）咖咖商城在规划与设计阶段，需要浏览和学习同类型专业电商平台的功能特性，深入对比优势与劣势，并思考要如何通过创造新颖的交互设计以提升用户的购物体验。系统需实现多角色管理，参考钟英杰等（2024）在外卖系统中的权限划分机制，确保业务安全[12]。
（2）系统的构建应重点关注于满足用户核心需求的基础功能模块，同时融入可以体现差异化来创造竞争优势的创新性核心功能，借鉴汪鹏等（2025）在互助系统中建立的互动功能，并确保这些功能在系统中得到显著展现[13]。
（3）在后台管理方面，需实现如姚佰允等（2025）在人员系统中所做的那样灵活的信息维护，包括商品分类管理、订单状态管理、评价内容管理等功能[14]，还需实现数据管理，将各种数据内容都存储在 MySQL 数据库中，保证了数据的安全和完整性。
（4）在技术选择上，为了提升开发效率并降低开发成本，还要同时兼顾系统的整体性、运行有效性和未来扩展性，系统采用了 SpringBoot 框架来搭建 B/S 架构。
（5）系统用户需要实现注册登录、个人资料管理、收货地址维护、商品浏览与搜索、购物车管理、订单创建与支付（模拟）、商品评价等功能。
（6）通过明确设计方向与策略，确保了系统搭建工作的有序推进，最终得以打造出既贴合用户需求又极具前瞻性的专业咖啡销售平台。
1.5 研究的主要方法
本文主要采用以下三种方法来推进“咖咖商城”系统的设计与研究工作。
（1）文献研究法
通过中国知网、万方数据、IEEE Xplore 等国内外学术数据库，梳理郭静等（2025）在票务系统等电商衍生平台中的主流技术应用[15]。同时深入研读 Zhao Z.（2025）关于 SpringBoot 构建复杂评价体系的文献[16]，重点分析了 B/S 架构在现代 Web 开发中的应用模式，以及电商系统在商品流转、订单并发处理等方面的核心技术痛点，为本项目的底层架构设计与技术选型提供了扎实的理论支撑。
（2）调查研究法
参考 SALAUDDIN U（2025）在垂直旅游网站调研中的痛点挖掘方法[17]，为了使系统功能真正贴合实际业务需求，在项目初期的需求分析阶段，面向部分独立咖啡店的经营者以及普通咖啡消费者开展了线上问卷调查与访谈。调研内容主要围绕线下门店在库存盘点、销售统计方面的难点，以及消费者在选购咖啡豆时对产地、风味描述的关注侧重点。通过对收集到的调研数据进行归纳与分析，明确了当前咖啡零售在“商品信息精细化展示”与“智能导购辅助”等方面的核心需求，为系统的功能模块划分提供了现实依据。
（3）技术实现法
本项目以解决实际工程问题为导向，严格遵循“需求分析—系统设计—编码实现—测试验证”的软件工程生命周期规范。在具体的系统实现阶段，采用 SpringBoot 结合 Thymeleaf 模板引擎的 B/S 架构模式。针对商品管理、购物车流转、订单结算以及 AI 智能咨询等核心业务，进行模块化的精细编码实现。
在系统开发进入尾声时，搭建本地测试环境，通过编写测试用例模拟普通用户与后台管理员的真实交互场景，对各项业务流程进行多轮测试与漏洞修复，最终保障系统具备良好的稳定性与可用性。
