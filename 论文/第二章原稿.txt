 2系统关键技术
本章节主要是对“咖咖商城”系统在开发过程中所使用的主要相关技术展开介绍，其中包括系统的 B/S 架构、后端的 SpringBoot 框架与 MyBatis 持久层技术、前端的 Thymeleaf 模板引擎技术、底层的 MySQL 数据库，以及项目构建所依赖的开发环境等方面。
2.1 系统架构选择
在进行“咖咖商城”的系统开发前，首先需要确定平台整体的网络运行架构。目前主流的软件架构主要分为 C/S（Client/Server，客户端/服务器）和 B/S（Browser/Server，浏览器/服务器）两种。考虑到电子商务平台需要面向广大的普通消费者，要求系统具备极高的易用性和跨平台访问能力，因此本项目最终确立了采用 B/S 架构进行开发。
B/S 架构是一种随着互联网技术的兴起而发展起来的网络结构模式。在这种架构体系下，系统的用户界面完全通过标准的 Web 浏览器来实现。前端（浏览器端）主要负责页面的视觉展示与部分轻量级的交互逻辑，而核心的业务逻辑处理、事务控制以及海量数据的存储计算，则全部集中部署在后端的服务器上。
 
图2-1 B/S模式网络架构图
对于本商城系统而言，采用 B/S 架构的优势尤为突出，主要体现在以下几个方面：
（1）极低的用户使用门槛：采用 B/S 架构意味着“零客户端”部署。消费者无需专门下载和安装任何繁琐的客户端应用，只要有一台能够连接互联网且装有主流浏览器的设备（如电脑、智能手机或平板），即可随时随地访问“咖咖商城”进行浏览与购物，极大地提升了平台的受众覆盖面。
（2）高效的系统维护与升级：对于系统管理员和开发者而言，当商城需要进行功能迭代、上新促销活动或修复底层 Bug 时，所有的代码更新和数据库调整工作仅需在服务器端完成即可。客户端浏览器在下次刷新访问时会自动获取到最新版本的页面与服务，这彻底打破了传统软件逐个升级客户端的困境，显著降低了后期的运维成本。
（3）优异的跨平台兼容性：B/S 架构依赖于标准化的 HTTP/HTTPS 协议与 Web 标准，因此天生具备良好的跨平台特性，能够无缝兼容 Windows、macOS 以及各类移动端操作系统，保障了多端数据流转的一致性。
在本项目中，B/S 架构配合后端的 SpringBoot 框架和前端的 Thymeleaf 模板引擎，成功构建了一个响应迅速、数据安全且交互流畅的在线咖啡销售环境。
2.2 关键性开发技术
2.2.1 SpringBoot框架
SpringBoot 作为构建 Java 企业级应用的主流框架，秉持“约定大于配置”的核心思想，显著简化了应用程序的初始化和部署流程。它通过集成嵌入式服务器（例如 Tomcat、Jetty 或 Undertow），让开发者能够直接以 JAR 包形式运行整个应用，从而消除了对外部环境的复杂依赖。
Yang F.（2025）在在线测试系统中也利用了该框架易于部署的特性快速搭建应用[18]。Wei T.（2022）详细阐述了 SpringBoot 生态在构建在线购物 Web 应用后端时的绝对优势，认为其内部集成的自动配置机制是提升开发效率的关键[19]。
本项目正是基于 SpringBoot 的这些特性，以确保咖咖商城系统在具备高效率、简化配置优势的同时，能够实现稳定、可靠的运行。
2.2.2 Thymeleaf 模板引擎
Thymeleaf 是一种现代化的服务器端 Java 模板引擎，专门为 Web 和独立环境设计。与传统的 JSP 不同，Thymeleaf 支持 HTML 原型，即在没有后端支持的情况下，模板文件也能在浏览器中正常显示静态内容。这一特性极大地便利了前后端分离的开发模式，使得开发者可以更直观地调试页面布局。在本项目中，Thymeleaf 与 SpringBoot 紧密集成，负责将后端的数据动态渲染到前端页面上，为用户提供响应迅速、交互友好的界面体验。
2.2.3 MyBatis 持久层框架
MyBatis 是一个优秀的基于 Java 的持久层框架，它内部封装了 JDBC，使开发者只需关注 SQL 语句本身，而无需花费精力去处理加载驱动、创建连接等繁杂的过程。MyBatis 通过 XML 或注解的方式将要执行的 SQL 语句配置起来，并通过 Java 对象和 Statement 中 SQL 的动态参数进行映射生成最终执行的 SQL 语句。在咖咖商城中，MyBatis 负责处理复杂的数据库操作，如商品的多条件搜索、订单的关联查询等，保证了数据访问的高效性和灵活性。
2.2.4 MySQL 数据库
MySQL 是一款基于 SQL 的开源关系型数据库管理系统，凭借其卓越的性能、高可靠性和低成本，在 Web 应用领域得到了广泛应用。其核心优势在于将数据结构化存储与高效查询能力深度融合。在本项目中，MySQL 5.7 被用于存储用户、商品、订单等所有关键业务数据。通过合理设计表结构和索引，确保了系统在面对大量数据时仍能保持良好的查询性能。
2.3 首页商品推荐算法
本系统首页的商品展示区域分为销量推荐和新品推荐两个模块。考虑到系统实际的数据量和复杂度，商城没有引入额外的算法模型库，而是采用了基于 SQL 数据库查询与 Java 内存排序相结合的基础方法来进行商品推流。
（1）按销量推荐商品 该部分功能主要用于向用户展示网站内最受欢迎的咖啡及器具。在代码实现上，系统通过 MyBatis 框架执行 SQL 语句，查询商品表（Commodity）并依据销量字段（sale_count）进行降序排列。为了控制首页页面的加载速度和展示数量，后端业务逻辑中使用了 PageHelper 分页组件，在查询时仅截取销量排名前 10 的数据结果返回给前端页面。
（2）按更新时间与折扣推荐新品 除了热门商品外，系统还需要为最新上架的产品提供一定的展示空间。首先，后端程序会从数据库中筛选处在正常上架状态（status = 1）的记录，依据发布时间（publish_time）降序查询出最新的 9 件商品。其次，在获取到这 9 个新品的对象集合后，Java 控制层（Controller）利用了 JDK 8 的 Stream 流式操作，以商品的折扣属性（Discount）为基准对列表进行了内存级别的升序排序。通过这一操作，折扣偏低、更为便宜的商品就会排在列表的前方优先展示。
通过上述两套简单的业务规则，系统完成了对商品基础数据的筛选与排序。这其中合理利用了 Java 底层 Stream 功能来处理部分排序任务，在一定程度上避免了完全依赖数据库拼接复杂限定查询，符合中低并发类网站的开发规范。
2.4 开发工具及环境
2.4.1 Navicat简介
Navicat 是一款功能强大的数据库管理软件，提供了直观的图形化界面，支持数据同步、备份恢复、导入导出及 SQL 查询等功能。它能简化数据库管理的各项任务并有效地提高工作效率。无论是对于开发人员还是数据库管理员来说，Navicat 都是一款非常实用的工具，本项目利用它进行数据库的可视化设计和数据维护。
2.4.2 IntelliJ IDEA简介
IntelliJ IDEA 是一款集成开发环境（IDE）软件，它为开发人员提供了非常丰富的工具和功能，如智能代码补全、强大的调试功能和性能分析工具等。它完美支持 SpringBoot、Maven 等构建工具，让开发人员能够非常轻松地管理和构建项目。本系统主要采用 Java 进行开发设计，借助 IDEA 这一强大的开发工具，有效提高了开发效率，加快了开发速度并提升了代码的质量。
2.4.3 运行环境
采用 Windows系统环境，为整个业务项目提供底层的系统编译与运行支持。
（1）操作系统：采用 Windows 10/11 环境，为整个业务项目提供底层的系统编译与运行支持。 
（2）开发语言环境：基于 Java 开发环境（具体采用 JDK 1.8 版本），为系统后端的业务逻辑编译以及 Stream 流操作提供底层的算力支撑。 
（3）数据库环境：使用 MySQL 关系型数据库，负责在底层统一存储本系统的买家账号、咖啡商品主干信息以及交易订单等各项业务流转数据。 
（4）依赖管理工具：采用 Maven 作为工程构建工具，主要用于系统中各种官方库与第三方 jar 包（如 Spring Boot 相关依赖项）的统一拉取与打包管理。
