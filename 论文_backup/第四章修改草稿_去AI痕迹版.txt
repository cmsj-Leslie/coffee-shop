### 4 系统详细设计

本章基于前期的需求与可行性分析结论，对“咖咖商城”进行系统级别的详细功能模块设计与架构解构。主要涵盖系统的整体宏观体系结构划分、各角色端口的核心业务用例设计、三层代码架构分层结构设计，以及支撑数据流转的底层数据库物理表设计。

#### 4.1 系统体系结构

咖咖商城采用 B/S（Browser/Server，浏览器/服务器）网络体系架构。整个电子商务项目在逻辑上分为前台消费端与后台运维端，对应的服务对象被抽象为管理员、普通游客与注册用户三大角色主体。
其中，前台用户端主要承载了商城主页加载、多条件商品搜索、购物车实体投递、订单结算流水以及特色 AI 智能问答等功能展示；后台管理端则收束了诸如 SKU 细录发布与状态下架、类目层级划分、订单配单发货、系统用户封禁及风险评价阻断等深层次操作。本系统的总体功能体系结构宏观拓扑结构如图4-1 所示。

#### 4.2 系统用例设计

在系统功能落地的详细阶段，必须针对不同权限端口的核心业务流进行边界和流转流程的设计。在本系统中，对应原定设计目录的控制端划分，将分为后台管理员端、前台游客端以及前台注册用户端的外围用例设计。

**4.2.1 管理员端业务设计**
管理员拥有后台最高写入权限，其核心业务操作集中于商品资源与促销规则的维保。以“商品管理”业务用例为例，管理员可通过调用发布接口注入新的咖啡豆 SKU 数据明细，并利用集成的阿里云 OSS 组件以字节流形式上传解析商品附图。此外，管理员还负责独立优惠券体系的规则下发，定制并推送各类门槛的满减与限时折扣卡券。在商品生命周期内，管理员有权触发“修改”动作，覆写数据库中原有的商品价格、库存水位或溯源描述。该商品在被后台标记为“下架并冻结”状态后将切断与前端视图的联结。该核心链路的严密控制保证了商城基础物品栏的数据安全。管理员视角的商品管理流程链路如图4-3 所示。

#### 4.3 系统架构设计

本系统的核心源码结构采用业内标准的“三层体系（MVC）”物理分隔模式进行项目结构搭建。代码体按执行职责被硬性切割为：衔接持久化媒介的实体层、响应前端网络行为的控制层，以及中置运算的业务逻辑层。模块化的切分大幅度降低了庞杂业务逻辑间的运行耦合，为后期的功能热拔插及断点纠偏提供了便利的基础。

**4.3.1 实体层设计**
实体层（Data/Entity Layer）在本系统中专职担任关系型持久化表单与 Java 虚拟对象域间的引力桥梁。工程底层利用轻量型的 MyBatis 框架包提供基座支撑。开发同学通过装配 Mapper 规范接口与相应的 XML SQL 执行体，将容易引发注入类破坏的原始拼接 SQL 升级为参数化预编译请求，并在查得结果后自动将字段映射注入到 Java Entity 对象中。实体层的深度下沉向控制层完美屏蔽了底层数据库版本的切换差异与繁冗的驱动步骤。

**4.3.2 控制层设计**
控制层（Controller Layer）驻守系统的外部网关，承载了 HTTP 请求报文鉴权与参数第一轮解析的职责。当前端系统页面（基于原生 HTML DOM 节点及 Thymeleaf 模板工具二次动态装填生成）向域发起例如刷新检索、增减购物车或文本投递等指令时，控制层拦截器首先截获并剖解出 URL 绑定值。随后抛交具体任务至底层逻辑代码中，并在一切运算就绪后，把状态封装反馈重定向至调用者的视图区域。

**4.3.3 业务逻辑层设计**
业务逻辑层（Service Layer）由 Spring Boot 框架的 IoC 容器贯穿管理周期，是所有电商运算法则中枢所在。当业务接口层接获控制器委托后，负责部署执行具体例如单价与折扣算法乘积、优惠卡包的门槛核销扣减（CouponService）、协同过滤推荐权重系数推演（RecommendService计算余弦相似度）、库存熔断阈值排查以及 AI 参数包组装等实际繁重事务代码。在进行关联写入（订单确立同时抹改库存）等具备高风险属性的连续操作时，业务层类中配置声明式事务注解（@Transactional）用以钳制多表同步动作序列的原子性，确保抛出异常时的数据库底层零折损回滚。

#### 4.4 系统数据库设计

基于关系型规范的底层数据库不仅仅是持久化保存静态参数物理容器，更是确保商场多维度流转数据自洽无冲突的血脉枢纽。在系统进入实际 DDL 建表阶段前，需要深刻剖析买家档案流、货品管理流以及交互聊天流等数据的依存连接关系，以夯实系统的数据存取支撑脚手架。

**4.4.1 数据库逻辑设计**
数据库的概念逻辑设计是一段将繁杂的业务用例实体提纯为抽象模型数据的映射编排过程。本项目借助专业的实体-联系法则（E-R 图）表述全局数据实体节点以及它们间复杂的基数网络映射连线（如单个账户挂载多条评价序列、单个单据捆绑特定地址）。系统的全量宏观概念性 E-R 图谱见图4-7。
