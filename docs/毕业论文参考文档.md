## 摘　要

随着电子商务行业的蓬勃发展和消费者对在线购物体验需求的不断提升，开发一款功能完善、体验友好的垂直领域商城系统具有重要的现实意义。本论文介绍了基于 Spring Boot 框架开发的咖咖商城系统的研究背景及应用现状，明确了本商城系统所研究的主要内容及核心功能。

论文从七个部分对该项目进行了描述，分别是绪论、相关技术介绍、系统需求分析、系统详细设计、系统实现、系统测试以及总结与展望。在绪论中，阐明了当代背景下研发咖咖商城的必要性及研究意义；在需求分析中，运用用例分析方法对系统的功能需求进行了梳理，将系统划分为前台用户端和后台管理端两大模块；在系统详细设计中，绘制了各功能模块的业务流程图，对登录认证、商品管理、购物车与订单、AI 智能咨询等核心模块进行了严谨的描述。

本系统采用 B/S 架构，后端基于 Spring Boot + MyBatis 框架进行搭建，前端页面使用 Thymeleaf 模板引擎结合 Bootstrap 框架进行设计与美化，数据库采用 MySQL 进行数据持久化存储，并集成了阿里云 OSS 实现商品图片的云端管理。系统创新性地引入了 AI 智能咨询模块，支持 DeepSeek 和 Gemini 双大语言模型，为用户提供智能化的咖啡咨询服务。在数据库设计中，分别采用实体联系图（E-R 图）和数据库物理结构设计对数据进行了系统分析。最后展示了咖咖商城的整体实现效果，并对该项目进行了总结与展望。

## 第一章 绪论

### 1.1 课题背景及意义

随着互联网技术和移动支付的快速发展，电子商务已成为人们日常生活中不可或缺的一部分。咖啡行业作为近年来增长迅速的消费领域，传统的线下门店模式已难以满足消费者日益增长的便捷购物需求。

本课题旨在设计与实现一个基于 **Spring Boot** 的在线咖啡商城系统——"咖咖商城"，该系统集商品展示、在线购买、订单管理、AI 智能咨询于一体，为用户提供一站式的咖啡购物体验，同时为商家提供高效的后台管理工具。

### 1.2 国内外研究现状

- **电商平台方面**：国内以淘宝、京东、拼多多为代表的综合电商平台已非常成熟，但针对垂直细分领域（如咖啡）的专业商城仍有发展空间。
- **技术框架方面**：Spring Boot 凭借"约定优于配置"的设计理念，已成为 Java Web 开发的主流框架。MyBatis 作为半自动化 ORM 框架，在灵活性和易用性之间取得了良好的平衡。
- **AI 应用方面**：以 DeepSeek、ChatGPT、Gemini 为代表的大语言模型 (LLM) 正在被广泛应用于客服、推荐等场景，为电商平台带来了智能化升级的可能。

### 1.3 主要研究内容

1. 基于 Spring Boot + MyBatis 的电商系统架构设计与实现
2. 前台用户端核心功能（商品浏览、购物车、订单、收藏、评价）的设计与开发
3. 后台管理端（商品管理、订单管理、用户管理）的设计与开发
4. AI 智能助手模块的集成（支持 DeepSeek / Gemini 双模型）
5. 阿里云 OSS 云存储、邮件服务等第三方服务的集成

### 2.2 Spring Boot 框架

Spring Boot 是基于 Spring 框架的快速开发工具，采用"约定优于配置"的设计理念，通过自动配置机制大幅降低了项目搭建的复杂度。本系统使用 Spring Boot 2.4.2 作为核心框架，主要利用以下特性：

- **自动配置**：如数据源、ThymeLeaf、邮件服务等均通过 `application.yml` 配置即可使用
- **内嵌 Tomcat**：无需单独部署 Web 服务器
- **Starter 依赖**：通过引入 spring-boot-starter-web、spring-boot-starter-thymeleaf 等 Starter 简化依赖管理

### 2.3 MyBatis 持久层框架

MyBatis 是一个半自动化的 ORM 框架，相比 Hibernate 的全自动映射，MyBatis 允许开发者直接编写 SQL，在保证灵活性的同时降低了学习成本。本系统使用 MyBatis 的 XML 映射方式管理 SQL 语句，配合 PageHelper 分页插件实现数据分页查询。

### 2.4 Thymeleaf 模板引擎

Thymeleaf 是一个现代化的 Java 模板引擎，支持 HTML5 自然模板，可以在不启动服务器的情况下直接在浏览器中预览页面。本系统通过 `th:replace` 片段引用机制实现了页面组件的复用。

### 2.5 大语言模型 (LLM) 技术

本系统集成了 DeepSeek 和 Google Gemini 两种大语言模型 API，通过策略模式实现了模型的灵活切换。AI 助手定位为"咖啡咨询顾问"，可回答咖啡推荐、冲泡技巧等问题。

## 第四章 系统详细设计

### 4.1 系统概要设计

咖咖商城是一个采用 B/S（Browser/Server，浏览器/服务器）架构的电子商务项目。本系统主要分为管理员和普通用户两个角色。其中，普通用户可以进行商城主页浏览、商品搜索、购物车管理、订单支付模拟、AI 智能咨询以及商品评价等功能；管理员则可以实现商品发布与上下架、分类管理、订单发货处理、系统用户管理及评价数据审核等功能。本系统的功能结构如图 4-1 所示。

本系统的用户登录功能涵盖了前台用户登录与后台管理员登录。用户在登录界面中输入正确格式的邮箱（账号）和密码后，点击登录按钮触发验证功能。系统将输入的信息与数据库 user 表中对应的数据进行比对。如果信息不匹配，系统会给出登录失败或账号密码错误的提示；信息匹配成功且角色权限核对无误，则成功登录并跳转至相应的主页或后台控制台。系统登录模块流程如图 4-2 所示。

### 4.3 数据库设计

在着手咖咖商城的数据库设计前，必须全面且深入地分析和理解本系统的各种业务需求，这涵盖了对交易数据流程、系统功能以及数据映射关系的了解。通过对需求的细致剖析，能够明确数据库中需要存储的数据之间的关联及数据类型。在此基础上确立了多个核心数据表，包括用户信息表、商品信息表、订单信息表、购物车表和 AI 聊天记录表等。这些数据库表的设计为系统的各项功能提供了坚实的数据支撑。

### 5.3 关键功能实现

#### 5.3.1 登录认证（拦截器）

通过 `LoginHandlerInterceptor` 拦截未登录请求，结合 `MvcConfig` 配置拦截路径，实现基于 Session 的登录认证机制。

#### 5.3.2 商品图片上传（阿里云 OSS）

通过 `OssClient` 组件封装阿里云 OSS SDK，支持商品图片的上传和 URL 返回，配置在 `application.yml` 中管理 Bucket、AccessKey 等信息。

#### 5.3.3 邮箱验证码（找回密码）

通过 `MailClient` 组件封装 Spring Mail，使用 QQ 邮箱 SMTP 发送密码找回邮件，支持用户忘记密码时通过邮箱找回。

#### 5.3.4 AI 智能助手

- **后端**：`AiConfig` 配置类读取 yml，`AiChatServiceImpl` 通过 Hutool 的 HttpUtil 调用 AI API
- **前端**：`ai-chat.js` 实现悬浮式聊天窗口，支持快捷问题、历史记录、模型切换
- **样式**：`ai-chat.css` (668行) 定义了完整的聊天组件样式，包含动画效果和响应式适配

## 第七章 总结与展望

### 7.1 总结

本系统成功实现了一个功能完善的在线咖啡商城，主要成果包括：

1. **完整的商城功能**：涵盖了用户注册登录、商品浏览搜索、购物车管理、订单全流程（下单→支付→发货→收货→评价）、收藏、地址管理等核心电商功能。
2. **高效的后台管理**：为管理员提供了商品管理、分类管理、订单管理、评论管理、用户管理等后台功能。
3. **AI 智能助手**：创新性地集成了 DeepSeek 和 Gemini 双 AI 模型，为用户提供咖啡咨询服务，提升了用户体验。
4. **第三方服务集成**：成功对接了阿里云 OSS（图片存储）和 QQ 邮箱（验证码发送），提高了系统的实用性。

### 7.2 展望

系统未来可在以下方面进行改进：

1. **支付功能**：接入微信支付/支付宝等真实支付接口
2. **推荐系统**：基于用户浏览和购买行为构建个性化推荐
3. **性能优化**：引入 Redis 缓存热点数据，优化高并发场景
4. **微服务化**：将系统拆分为商品服务、订单服务、用户服务等微服务
5. **移动端适配**：开发小程序或移动端 APP
6. **客服系统**：集成在线客服功能，实现用户与商家的实时沟通
