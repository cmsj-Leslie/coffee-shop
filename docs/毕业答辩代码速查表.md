## 一、项目整体架构

```
com.coffeeshop/
├── CoffeeShopApplication.java     ← 启动类
├── config/                         ← 配置层
├── component/                      ← 组件层（拦截器、工具类）
├── controller/                     ← 控制层（接收请求）
├── service/                        ← 业务逻辑层（接口）
│   └── impl/                       ← 业务逻辑层（实现）
├── mapper/                         ← 数据访问层（MyBatis Mapper 接口）
├── entity/                         ← 实体类（对应数据库表）
└── dto/                            ← 数据传输对象
```

**分层原则（MVC 模式）：**
- 请求进来 → `Controller` 接收 → 调用 `Service` 处理业务 → `Service` 调 `Mapper` 操作数据库
- 模板引擎：Thymeleaf，模板文件在 `resources/templates/`
- SQL 映射：MyBatis XML，文件在 `resources/mybatis/mapper/`

## 五、关键设计模式

| 设计模式 | 体现位置 | 说明 |
|---------|---------|------|
| **MVC 分层** | controller → service → mapper | 职责分离，各层独立 |
| **模板方法** | `BaseController.java` | 所有 Controller 继承，共享 Session/Service 注入 |
| **拦截器模式** | `LoginHandlerInterceptor` + `MvcConfig` | 统一登录校验 |
| **Builder 模式** | 所有 Entity 类 | Lombok `@Builder` 链式构造对象 |
| **策略模式** | `AiChatServiceImpl.chat()` | 根据 provider 选择不同 AI API |
| **依赖注入** | `@Autowired` 遍全项目 | Spring IoC 容器管理 Bean 生命周期 |
| **配置绑定** | `AiConfig` + `@ConfigurationProperties` | yml 配置自动映射到 Java 对象 |
